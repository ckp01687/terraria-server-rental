## 先算四个数字，再谈买哪台

泰拉瑞亚对硬件的要求比同期的我的世界轻得多，但它有四个变量会直接决定你该花多少钱。

**在线人数**。2–4 人的熟人局，2 核 4G 就够跑；6–10 人并且长期开着，4 核 8G 会舒服很多。

**是否上模组**。原版服务端本身很省资源，1GB 内存就能跑起来，官方模板给出的最低内存标注是 1024MB。但换成 tModLoader 之后完全不是一个量级——多个来源的托管建议是原版小团体 2GB 起步，模组服直接按 4–8GB 准备。

**世界大小与难度**。Small / Medium / Large 三档，Large 世界首次生成要等几分钟，之后常驻的内存占用也更高。刷怪量、事件密度同样影响 CPU。

**每天开多久**。这一条决定了你该选动态计费还是固定计费，后面细说。

一个常被忽略的细节：泰拉瑞亚服务端主要吃单核性能，多核堆到 8 核并不会让 5 个人的世界更流畅。所以"高主频的低核数机器"通常比"低主频的堆核机器"更适合开泰拉瑞亚服。

### 固定计费还是动态计费

雨云游戏云有两种计费方式，选错一个月可能多花几十块。

**固定计费**就是传统的按月包干，不管 CPU 用多少都一个价，适合假期天天开、周末必开的稳定服。

**动态计费的逻辑是"低月租 + CPU 电费"**：CPU 使用率以 20% 为基准线，低于 20% 不算耗电，超出部分按日结算。它的好处是闲置不花钱，坏处是活跃的生存服 CPU 长期压在高位，电量会一路累积。

经验判断很简单：**你的服每天有人在线超过两三个小时，选固定计费；只是偶尔约一群人打两把 boss，选动态计费。** 拿不准就先用动态计费跑一周，看后台的电量账单自己就明白了。

## 从购买到队友能进服：完整流程

### 系统选 Windows 还是 Linux

泰拉瑞亚服务端在 Windows 上依赖 .NET Framework，新版 Linux 上依赖 .NET 运行时，用 TShock 也是走 .NET 路线。如果你完全不熟命令行，直接选 Windows Server 镜像，解压就能双击运行，图形化远程桌面操作基本没有学习成本。缺点是 Windows 自身会吃掉几百 MB 内存，2 核 2G 的机器跑起来会偏紧。

Linux 更省资源，2 核 2G 也能跑得开，但你要会用 `screen` 或者 `systemd` 把进程挂到后台。

### 把服务端跑起来

Linux 下的大致顺序是这样的（Windows 直接图形界面操作，逻辑相同）：

bash
# 装必要工具
sudo apt update && sudo apt install wget unzip screen
# 下载服务端（把版本号替换成当前版本）
sudo wget https://terraria.org/api/download/pc-dedicated-server/terraria-server-XXXX.zip
sudo unzip terraria-server-XXXX.zip
cd XXXX/Linux
sudo chmod +x TerrariaServer.bin.x86_64


首次运行会进入交互式配置：选世界大小（Small / Medium / Large）、难度、最大人数、端口。世界生成要等几分钟，Large 世界尤其慢，期间服务器不接受连接，属于正常现象。

配置文件也可以写成 `serverconfig.txt`，之后用 `./TerrariaServer.bin.x86_64 -config serverconfig.txt` 启动，免去每次手动选世界。常用字段包括 `world`、`maxplayers`、`port`、`password`、`motd`。

### 7777 端口这一步最容易卡住

**服务器显示"已启动"但队友连不上，九成问题出在端口。** 泰拉瑞亚默认走 TCP 7777，你需要确认三件事：控制台安全组放行了 7777/tcp、服务器系统防火墙也放行了同一端口、服务端日志里确实打印了监听信息。

两行命令足够：

bash
sudo ufw allow 7777/tcp
sudo ufw allow 22/tcp
sudo ufw enable


改完别忘了重启服务端。队友那边在游戏里走 Multiplayer → Join via IP，先填服务器公网 IP，再填 7777 就行。

> 这里就是租服务器相比家用电脑的最大区别：机器自带固定公网 IP，你不用碰路由器，也不用担心 ISP 那边换了 IP 之后要重新通知所有人。

### 让它一直在后台活着

直接在当前终端跑服务端，SSH 一断服务就停。用 `screen` 建一个会话来跑，按 `Ctrl + A` 再按 `D` 脱离，进程继续运转，下次 `screen -r` 回去看日志。用 systemd 做成服务则更规范，还能开机自启。

长期运行的服建议加两样东西：**每天凌晨定时重启一次**（`0 3 * * * systemctl restart terraria`），清掉长时间运行累积的内存占用；以及**定期备份世界文件**——Linux 下存档在 `~/.local/share/Terraria/Worlds/`，Windows 下在服务端目录里。一个开了两百小时的世界没了，比服务器本身贵得多。

## 常见问题

**能装 TShock 或者 tModLoader 吗？**
可以，前提是你选的是 VPS 形态而不是被面板锁死启动参数的面板版。TShock 需要 .NET 运行时，tModLoader 对内存的要求高于原版，建议 4GB 起步。模组服还有个容易踩的坑：所有玩家装的模组版本必须和服务端一致，否则直接连不上。

**几个人开始会卡？**
原版服 2 核 4G 跑十几个人一般没问题，真正让 TPS 掉下来的通常是：模组数量、Large 世界的实体数量、以及服务端视距设置过高。卡的时候先降视距，再考虑升级配置。

**动态计费会不会最后比固定还贵？**
会，如果你的服每天有人在线三小时以上。动态计费省钱的前提是"经常没人玩"。

**服务器关机了世界会不会丢？**
不会。世界文件是存在磁盘上的，重启后重新加载即可。真正会丢的情况是磁盘写满或者进程权限不对导致存档没写下去，所以定时备份不能省。

**面板版和 VPS 版能不能中途换？**
CPU 机型不能随意更换，买之前想清楚。内存、带宽、硬盘这类配置可以在控制台升降级，也能升级套餐，所以起步时不必一次买满——先按当前人数买够，人多了再往上加。
